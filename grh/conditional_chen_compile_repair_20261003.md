## 故障定位

内置编译器返回 `Unable to find standard directories for platform`，尚未进入 TeX 源码处理。
本机 USERPROFILE、APPDATA、LOCALAPPDATA 均正常。相同源稿使用已安装的
TeX Live 2025 编译成功；应用自带的 Tectonic 0.17.0+20260731 在普通进程中也编译成功。
这排除了稿件语法错误和 Tectonic 可执行文件损坏作为这次中断的原因。

只读检查当前应用 26.928.4866.0 的编译调用发现，Windows 内置预览始终经专用沙箱
启动 Tectonic，替换用户目录并设置缓存目录，没有可用的本机编译器选择设置。
据此，故障定位到应用沙箱中的标准目录初始化；具体的 Windows API 失败原因尚未取得。
没有证据能够确定触发故障的升级或系统变动时间。

Tectonic 的[目录实现](https://docs.rs/tectonic_io_base/latest/src/tectonic_io_base/app_dirs.rs.html)
在 `ProjectDirs::from` 失败时产生这一报错。
其[配置读取实现](https://raw.githubusercontent.com/tectonic-typesetting/tectonic/tectonic@0.17.0/src/config.rs)
在处理文档前查询用户配置目录；仅设置 TECTONIC_CACHE_DIR 不会绕过这一步。
当前诊断不支持通过修改稿件或清空项目辅助文件修复内置目录故障。

源文件原稿保存在 tmp/compile_repair_20261003/conditional_chen_grh_bridge.tex。

PDF 链接目标。数学参数、阈值、假设、结论及引用键没有改变。
