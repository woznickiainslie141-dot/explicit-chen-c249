# Explicit Chen theorem at c = 24.9

**Author:** Cheng Huang  
**Affiliation:** Shanghai Jiaotong University

This private research archive contains a complete, reproducible certificate
for the following result:

> For every even integer `N` with `log log N >= 24.9`, one has
> `D_{1,2}(N) > 0`.

The proof package contains the LaTeX manuscript, the 34 Arb/ACB interval
integrals, 136 structural assertions, the unique forward ledger, the external
source records used in the audit, and an independently tested reproduction
script.

Start with [`README_REPRODUCE.md`](README_REPRODUCE.md). The theorem-level
audit is in [`final_audit.md`](final_audit.md), and the latest package validation
is in [`VALIDATION_REPORT.md`](VALIDATION_REPORT.md).
